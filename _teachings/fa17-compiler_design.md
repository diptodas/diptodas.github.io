## Course Overview

This course teaches the compilation process so that students understand how a program moves from source code to target code and can implement basic compiler tools. The lecture covered the theory of each compiler phase, and the accompanying lab gave students hands-on practice building them.

## Learning Objectives

After completing this course, students will be able to:

- Define and describe compiler design
- Classify and compare the phases of a compiler
- Explain the compilation process
- Implement basic compiler tools

## Assessment

Short and broad questions, quizzes, class tests, a midterm and final exam, assignments, and presentations.
