## Course Overview

This course gives students a working knowledge of how to design and analyze algorithms: searching and sorting in linear and non-linear data structures, graph algorithms, and dynamic programming, with practical applications to everyday problems. Lectures used whiteboard derivations and slides, and lab sessions gave students practice implementing the algorithms.

## Learning Objectives

After completing this course, students will be able to:

- Define and develop searching algorithms for linear and non-linear data structures
- Develop and apply different sorting algorithms
- Solve practical problems using these algorithms
- Analyze, design, and propose new algorithms for sorting and searching
- Distinguish among sorting algorithms and recommend one for a given situation
